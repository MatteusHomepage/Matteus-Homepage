Currency Converter - FAQ
To use the currency converter, type /con in the input field. Pressing delete just after the engine chip exits converter mode. Enter your conversion using the following format: Amount FROM TO, with standard three-letter currency codes supported by Google. Example: 100 USD EUR
The amount is entered first, followed by the source currency and the target currency. All conversions use up-to-date exchange rates. Make sure the currency codes are valid to ensure accurate results.
Gold (XAU) and Silver (XAG) also work with conversion. Example: 100 USD XAG

Calculator - FAQ
To access the calculator, type /calc in the input field. This enables math mode and allows you to enter calculations directly. You can use common mathematical operators such as addition, subtracion, multiplication, division, and parentheses to control order of operations. Standard math rules apply. Example: (5 + 3) x 4 / 2
To use Addition, type "+", For Subtraction, type "-", If you want Multiplication, type "*" And to use Division, type "/". You can also use parentheses

Engines - FAQ
Engines let you quickly route your input to a specific service or tool. Each engine is activated by typing its shortcut at the start of the input, followed by your query. All engines start with a slash "/".
For a list of all inputs, visit Menu 🠮 Info 🠮 Controls 🠮 Engines List or >engines. To remove the engine mode, press Delete when your text cursor is just after the chip image.

Bookmarks - FAQ
Bookmarks let you save your favorite websites for quick access. You can organize them into folders and access them instantly using Shift + B or through the menu. To add a bookmark, open Menu → Bookmarks → + Add Folder (to create a folder first), then click on the folder and use + Add Shortcut.
Each bookmark can have a custom name (up to 20 characters), URL, color, and even a custom icon image. You can drag and drop images directly onto the upload area or the background button. Folders can hold up to 12 bookmarks each, and you can have up to 12 folders total.
Right-click any bookmark or folder to Edit, Move, or Delete it. Move mode lets you reorder items using arrow keys - press Enter to confirm or Esc to cancel. You can also manage bookmarks using commands like >bookmark add [folder name] or >bookmark delete [bookmark name].
Export your bookmarks as JSON using Manage Bookmarks → Export JSON. This creates a backup file you can import later. Import supports both the custom format and simple bookmark arrays. Your bookmarks are automatically saved to your browser's localStorage.

Commands - FAQ
Command Mode Command Mode lets you execute quick actions directly from the input. To activate it, type > followed by a space or by typing /cmd. Once active, you can enter commands to perform tasks without navigating away from the input. Commands are interpreted immediately, making actions faster and more efficient.
Use Command Mode whenever you want to control features quickly and directly. A list of all current commands is available at Menu 🠮 Info 🠮 Controls Commands List or by typing >Commands
